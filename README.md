Data Scientist & Ingénieur IA · Développeur Python Full Stack.
Co-fondateur de [SOINAA-TECH](https://soinaa-tech.com), co-développeur de [Bahati Marketplace](https://bahati-marketplace.tech).

**Site :** https://portfolio-sadam.vercel.app

## Stack

- React + Vite
- Tailwind CSS v4 (`@tailwindcss/vite`)
- Framer Motion
- React Router v6
- Déploiement statique sur Vercel

## Pages

- **Accueil** : présentation, expertises, entreprises
- **À propos** : expérience, formation, compétences, langues
- **Projets** : Bahati Marketplace, SCHOOLIA, Mirontsy Smart Commune, détection de fraude bancaire
- **Contact** : coordonnées et formulaire

Les projets sont définis dans [`src/data/projects.js`](src/data/projects.js).

## Lancer en local

```bash
npm install
npm run dev
```
